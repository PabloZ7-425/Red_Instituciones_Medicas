# Interfaz web

La interfaz React usa Vite y consume la API de Django. La [guía de la raíz](../README.md) explica cómo iniciar el sistema completo y ver los flujos con datos ficticios persistentes.

- src/api contiene los clientes HTTP.
- src/clinical contiene el expediente y las acciones de atención.
- src/features reúne las vistas propias de cada institución.
- tests cubre los contratos del cliente y los recorridos en navegador.

La [documentación de integración](../docs/implementacion/README.md) explica los permisos, la separación de motores y los escenarios verificados.
